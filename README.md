# Sports M3U playlist

This repository publishes `playlist.m3u` at a constant GitHub URL. The playlist is regenerated by a thin client that could be deployed on a Linux box (Mini PC).

Linux Deployment Guide (Mini PC)
This guide will walk you through setting up your scraper to run autonomously every 30 minutes on your new Linux mini PC.

By running it locally on your network, the generated 1freecdn.xyz tokens will perfectly match your home IP address, allowing your TV to play them seamlessly!

1. Install Prerequisites
First, open a terminal on your Linux box and ensure you have Git, Node.js (v20+), and the required system libraries for Puppeteer (headless Chrome).

bash

# Update package list
sudo apt update
# Install Git and necessary dependencies for Puppeteer's headless Chrome
sudo apt install -y git curl libnss3 libnspr4 libatk1.0-0 libatk-bridge2.0-0 libcups2 libdrm2 libxkbcommon0 libxcomposite1 libxdamage1 libxfixes3 libxrandr2 libgbm1 libasound2
# Install Node.js (via NodeSource)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
2. Clone the Repository & Configure
Clone your repository to a permanent location (e.g., your home directory).

bash

cd ~
git clone https://github.com/sambath-creator/sports-enthusiast.git
cd sports-enthusiast
# Install Node packages
npm install
Create your .env file just like you did on your Windows machine:

bash

nano .env
Paste your Supabase credentials inside, then press Ctrl+O, Enter, and Ctrl+X to save and exit:

env

SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_anon_key
3. Set Up GitHub Authentication (Crucial for Automation)
Since the script will run automatically in the background without human intervention, it cannot show a popup to ask for your GitHub password when running npm run sync. You need to configure a Personal Access Token (PAT) or an SSH Key.

The easiest method is to embed a Personal Access Token into the remote URL:

Generate a classic PAT on GitHub (with repo permissions).
Tell Git to use it for this repository:
bash

git remote set-url origin https://<YOUR_GITHUB_USERNAME>:<YOUR_PAT_TOKEN>@github.com/sambath-creator/sports-enthusiast.git
(Now, git push will work instantly without any prompts!)

4. Test the Script Manually
Before automating it, make sure the script runs perfectly on Linux:

bash

npm run sync
If this completes successfully and pushes to GitHub, you are ready for automation!

5. Automate with Cron (Every 30 mins)
Linux uses cron to schedule background tasks.

Open your crontab editor:
bash

crontab -e
(If prompted to choose an editor, select nano)

Paste the following line at the absolute bottom of the file. Important: Replace /home/yourusername/ with the actual path to your cloned folder, and ensure the path to npm is correct (usually /usr/bin/npm).
bash

*/30 * * * * cd /home/yourusername/sports-enthusiast && /usr/bin/npm run sync >> /home/yourusername/sports-enthusiast/cron.log 2>&1
Save and exit (Ctrl+O, Enter, Ctrl+X).
TIP

Check your logs Because we added >> cron.log 2>&1 to the cron job, you can check exactly what the scraper is doing in the background at any time by running: tail -f ~/sports-enthusiast/cron.log
